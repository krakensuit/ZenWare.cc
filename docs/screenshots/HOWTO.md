# Screenshots / Скриншоты

Drop game screenshots here as PNG, then they get wired into `README.md`.
Кидай сюда скриншоты из игры в PNG — после этого они появятся в `README.md`.

## Wanted files / Нужные файлы

| File | What to capture / Что снять |
|---|---|
| `menu.png` | Open menu (`INSERT`) over gameplay, 1920x1080 |
| `esp.png` | ESP boxes + radar visible, horde or SI in frame |
| `loader.png` | Loader main window (use Win+Shift+S) |

## How to take / Как снять

1. Launch the game with `-insecure`, local map (`map c1m1_hotel`).
   Запусти игру с `-insecure`, локальная карта.
2. Open the menu with `INSERT` for `menu.png`.
   Открой меню на `INSERT` для `menu.png`.
3. Steam screenshot key (`F12` by default) or Win+Shift+S, save as PNG here.
   Клавиша скриншота Steam (`F12`) или Win+Shift+S, сохрани PNG сюда.
4. No nicknames / Steam IDs of other players in frame if possible.
   По возможности без ников посторонних игроков в кадре.
